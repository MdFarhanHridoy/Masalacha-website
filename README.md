## 🌟 About Masalacha

Masalacha is a social matchmaking and friendship platform designed for Bangladeshis both at home and abroad. It connects people from across the world into one unified space, making it easier to build meaningful social connections within the Bangladeshi community.

**Key Features:**
- 🌍 Connect with Bangladeshis worldwide
- 💕 Social matchmaking and friendship building
- 📱 Available on iOS and Android
- 🎯 Targeted at Bangladeshi community
- 🔒 Safe and trusted platform

## 🎨 Design Features

### Color Scheme
- **Primary**: `#F8BD9C` (Warm coral)
- **Dark**: `#212529` (Dark gray)
- **Secondary**: `#3f37c9` (Deep purple)
- **Accent**: `#4895ef` (Bright blue)
- **Light**: `#f8f9fa` (Light gray)

### Typography
- **Font Family**: Poppins (Google Fonts)
- **Responsive Scaling**: Automatically adjusts based on screen size

### Responsive Breakpoints

| Breakpoint | Screen Width | Device Types | Layout Changes |
|---|---|---|---|
| **Extra Small** | ≤ 575.98px | Large phones | Stacked hero, full-width buttons, hamburger menu, single carousel card, bottom-centered timer card |
| **Small** | 576px - 767.98px | Landscape phones, small tablets | Stacked hero, adjusted navigation, two carousel cards, bottom-centered timer card |
| **Medium** | 768px - 991.98px | Tablets | Two-column hero layout, right-side timer card |
| **Large** | 992px - 1199.98px | Desktops | Two-column hero, full desktop features, right-side timer card |
| **Extra Large** | ≥ 1200px | Large desktops | Centered container layout, full desktop features, right-side timer card |

**Key Responsive Behaviors:**
- **< 768px**: Mobile layout with hamburger menu, stacked hero section, full-width download buttons, timer card centered at bottom
- **≥ 768px**: Tablet/desktop layout with horizontal navigation, two-column hero, timer card positioned on right side
- **768px exactly** (iPad Mini): Uses tablet/desktop positioning (right-side timer card)

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools or dependencies required

### Running Locally

1. Clone the repository:
```bash
git clone https://github.com/yourusername/masalacha-website.git
```

2. Navigate to the project directory:
```bash
cd masalacha-website
```

3. Open the website in your browser:
```bash
# Option 1: Direct file open
start matchmakingappv1.0/index.html

# Option 2: Using a local server (recommended)
npx http-server -p 8080
# Then visit http://localhost:8080/matchmakingappv1.0/
```
