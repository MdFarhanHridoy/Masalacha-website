# Plan: Timer Card Fixes + Bigger Mobile Download Buttons

## Goals
1. When `.launch-timer-card` has the `.collapsed` class, hide the content (`.launch-text` and `.timer`) so only the card background and the toggle arrow button remain visible.
2. On mobile screens, the toggle arrow should be centered on the card (not on the left side).
3. On iPad Mini (768 x 1024) and other tablets with width ≥768px, the timer card should be positioned on the right side (like desktop), not at the bottom (like mobile).
4. Make the IOS and ANDROID download buttons bigger on mobile screens only — increase button width/height and icon size, but reduce button text ("IOS" and "ANDROID") size to smaller than 14px. Desktop and tablet sizes must not change.

## Change 2: Center toggle arrow on mobile (fix collapsed state override)

### Problem Identified
There is a rule at line 99–101:
```css
/* When collapsed */
.launch-timer-card.collapsed .timer-toggle {
    left: -18px;
}
```

This rule is **unconditional** and overrides the mobile centering (`left: 50%`) even on mobile screens because it doesn't have a media query qualifier.

### Solution: Restrict the override to desktop only

Replace the unconditional rule with a desktop-only media query:

```css
/* When collapsed - DESKTOP ONLY */
@media (min-width: 769px) {
    .launch-timer-card.collapsed .timer-toggle {
        left: -18px;
    }
}
```

**Why this works:**
- Desktop (≥769px): Toggle button stays at `left: -18px` when collapsed (existing behavior)
- Mobile (≤767px): Toggle button uses `left: 50%` with `transform: translateX(-50%)` from the existing mobile media query (lines 171–179), keeping it centered whether collapsed or expanded

## Change 3: Fix iPad Mini positioning (adjust mobile breakpoint)

### Problem Identified
The mobile media query is currently set to `@media (max-width: 768px)` at line 145. This includes the iPad Mini (768px width), causing the timer card to be positioned at the bottom (mobile style) instead of on the right side (tablet/desktop style).

iPad Mini has a width of 768px, which is a common tablet resolution. Tablets should get the right-side positioning, not the bottom-centered positioning.

### Solution: Change breakpoint from 768px to 767px

Update line 145:
```css
/* Before */
@media (max-width: 768px) {

/* After */
@media (max-width: 767px) {
```

**Why this works:**
- **Desktop/Tablet (≥768px)**: Timer card uses default positioning (`right: 20px; top: 30%; transform: translateY(-50%)`), appearing on the right side
- **Mobile (≤767px)**: Timer card uses mobile positioning (`left: 50%; bottom: 20px; transform: translateX(-50%)`), appearing at the bottom, centered

**Impact:**
- iPad Mini (768px) → Right side (tablet/desktop style) ✅
- Smaller tablets (768px+) → Right side
- Large phones and small tablets (<768px) → Bottom centered
